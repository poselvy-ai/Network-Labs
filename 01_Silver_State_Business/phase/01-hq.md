# HQ Build Phase

The Silver State build is broken into logical phases. This phase builds the headquarters site.

| # | Step | Status|
|---|------|-------|
| 1 | Cable infrastructure according to the Physical Diagram and the *Physical Connection* table in addressing.| Complete|
| 2 | Switches: VLANs, trunks, STP, and hardening | Complete |
| 3 | HQRT1: subinterfaces (E0/1.10–.99) and DHCP pools | Complete |
| 4 | ISP1, then PAT and the default route on HQRT1 | Complete |
| 5 | SRV1: static IP, DNS, web build| Complete | 
| 6 | Test PCs | Complete |
